# Cora × Soma — Post-PCI Recovery Prototype

Concept prototype for Imperial Hackathon 2026, Challenge 4 (Healthbridge GBA).

**Live demo:** https://yulan32feixiao.github.io/cora-prototype/

- **Patient app** (phone view): daily check-in, Western + Tongxinluo medication checklist, Soma night report, herb–drug food checker, visit prep.
- **Doctor view**: 8-week longitudinal recovery report (Module D).

All data is simulated. Cora is a recovery-support tool. It does not diagnose or prescribe.
