# Cora × Soma — Post-PCI Recovery Prototype

Concept prototype for Imperial Hackathon 2026, Challenge 4 (Healthbridge GBA).

**Live demo:** https://yulan32feixiao.github.io/cora-prototype/

## Try it
- **Language:** EN / 粵 (Cantonese, Traditional) / 普 (Mandarin, Simplified), plus 🔊 read-aloud.
- **Demo: 8 weeks in.** Mr Chan's app with 8 weeks of simulated data.
- **New user (empty).** A real first launch: onboarding (language → eHealth+ consent → medicine times → Soma pairing → daily routine), then empty screens that explain what appears and when.
- **Patient app / Doctor view.** The doctor view is the Module D 8-week report.
- **? How to use** on every screen explains how to use it and which patient need it meets.

Health content is backed by the sources in [SOURCES.md](SOURCES.md). All data is simulated. Cora is a recovery-support tool. It does not diagnose or prescribe.
